0:32 / 0:45
Hari ini mencoba menyiapkan adaptasi UI Nyawtat untuk desktop Windows. Layout split-pane terasa sangat intuitif karena memanfaatkan lebar layar monitor tanpa perlu pop-up yang menutupi seluruh layar. Beberapa hal yang dipelajari dan disesuaikan: 1. Navigasi vertikal (sidebar) jauh lebih nyaman digunakan dengan mouse dibandingkan bottom navigation bar di bawah layar. 2. Pintasan keyboard (Ctrl+N, Ctrl+1..4, Ctrl+K) membuat pengoperasian menjadi sangat gesit untuk pengguna desktop. 3. Dukungan database lokal SQLite dan secure storage berjalan mulus di Windows.

Rekam Catatan Suara
Bicara langsung lewat mikrofon PC / laptop
1. Navigasi Vertikal (Sidebar) vs Bottom Dock Pada layar lebar desktop (≥ 768px), navigasi berpindah ke sisi kiri (Navigation Rail / Sidebar) dengan tombol Catat Cepat lebar dan shortcut hint (Ctrl+N). Pada layar ponsel, tetap menggunakan floating bottom dock.
2. Split-Pane (Master-Detail) di Jurnal Daftar entri jurnal dan pembaca/editor berada berdampingan. Pengguna tidak perlu membuka modal penuh yang menutupi layar hanya untuk membaca satu entri.
3. Dashboard 2-Kolom & Chart Grid Memanfaatkan ruang horizontal desktop: kartu ringkasan dan linimasa ditempatkan di sisi kiri, sementara dompet aktif dan tips maskot di sisi kanan. Pada Laporan, grafik donut dan mingguan tampil berdampingan.
