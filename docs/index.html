FAQ

Pertanyaan.

Apakah Nyawtat gratis?

Ya. Tidak ada iklan, tidak ada versi premium, dan tidak ada langganan.

Apakah butuh internet?

Tidak. Internet hanya dipakai saat kamu login untuk sinkron atau mencadangkan ke Google Drive.

Di mana dataku disimpan?

Di HP-mu. Kalau login, salinannya disinkronkan ke cloud; cadangan masuk ke Google Drive milikmu sebagai file Excel.

Bisa pindahan dari Money Manager?

Bisa. Di Pengaturan › Data, pilih Pulihkan / Impor lalu pilih file .mmbak, .sqlite, atau .xlsx.

Ada versi iPhone?

Belum. Nyawtat dibuat untuk Android lebih dulu.

Apakah update menghapus catatan?

Tidak. Pasang APK baru di atas yang lama dan semuanya tetap ada.
