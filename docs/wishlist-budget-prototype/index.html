💼 Saldo Dompet Nyawtat Saat Ini

Wishlist dapat diikatkan ke dompet tujuan, dan saat Anda menyetor tabungan, Anda dapat memilih dari dompet mana uang tersebut disisihkan:

💡 1. Wishlist Terintegrasi Pilihan Dompet

Setiap target barang impian kini memiliki Dompet Tempat Penyimpanan:

  • Pilihan Fleksibel: Pengguna dapat menaruh impian di rekening khusus (misal: Bank BCA Tabungan, Bibit, atau Dompet Tunai).
  • Alur Setor Tabungan: Saat klik "+ Nabung", muncul dialog untuk memilih dompet sumber dan nominal yang ingin disisihkan.
  • Otomatis Menghitung: Rincian target per bulan & harian dihitung otomatis dari sisa kekurangan target.

⚠️ 2. Warning Reminder Tagihan

Tagihan dengan tanggal jatuh tempo (*due date*):

  • H-2 s/d H-0: Peringatan darurat (merah) dengan badge "⚡ 2 hari lagi!".
  • Bayar Cepat: Klik "Bayar" langsung memotong saldo dompet terkait dan mencatat transaksi lunas.

🎯 3. Global Budgeting & Warning Threshold

  • < 75%: Aman (Kucing gembira 😺).
  • 75% - 99%: Waspada Kuning (⚠️ mendekati batas).
  • ≥ 100%: Bahaya Merah (🚨 budget jebol!). Maskot kucing panik 🙀.

🔥 4. Gamifikasi Streak Api

Menyetor tabungan ke wishlist sekarang otomatis mencentang rutinitas harian dan mempertahankan api streak 🔥!
